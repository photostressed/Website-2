Legendas

Esta página só funciona dentro da app Legendas no Mac.

Preparação só é preciso fazer uma vez

  1. Instalar o ffmpeg e o Whisper

    No Terminal, se ainda não tens o Homebrew, instala-o primeiro:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    Depois instala os dois programas:

    brew install ffmpeg whisper-cpp
  2. Descarregar o modelo de reconhecimento de voz

    Whisper large-v3-turbo · cerca de 1,6 GB · fica guardado no Mac e funciona sem internet.

Arrasta para aqui um vídeo ou áudio Para as legendas coincidirem com a montagem, exporta do DaVinci o áudio da timeline (ou o vídeo final).
Língua do vídeo

A tradução usa o DeepL (português de Portugal). Cria uma conta gratuita em deepl.com/pro-api (500 000 caracteres por mês, chega para muitas horas de vídeo) e cola aqui a chave.

Pré-visualização indisponível para este formato. As legendas funcionam na mesma.

Clica no número de uma legenda para saltar para esse momento. No DaVinci: File → Import → Subtitle e arrasta o .srt para o início da timeline.
